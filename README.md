# 619 Brickell · Menú interactivo

Prototipo de menú interactivo para 619 Brickell Residences (Miami): torre, plantas, residencias, vistas 360° reales y maqueta 3D.

- `index.html`: aplicación completa (HTML, CSS y JavaScript, sin frameworks; WebGL propio).
- `assets/`: renders, plantas, láminas del proyecto y panorámicas 360°.

Desarrollado con herramientas asistidas por IA (Claude). Material de referencia: planos y renders de Siegel Suarez Architects.

## Ver en local
```
python3 -m http.server 8000
```
y abrir http://localhost:8000
